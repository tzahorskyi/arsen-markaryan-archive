# Арсен Маркарян — Полный видеоархив (967+ видео)

Веб-приложение со всеми подкастами, стримами, дебатами, вебинарами и архивами Periscope (2014–2025 гг.) Арсена Маркаряна.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/tzahorskyi/arsen-markaryan-archive)

## Особенности
- 🎬 **967 уникальных видео** без Shorts.
- ⚡ **Мгновенный поиск** по темам, гостям и названиям.
- 📂 **Интерактивные категории** (Интервью, Дебаты, Перископы 2014–2020, Эффективный, Биохакинг, Психология, Деньги).
- ▶️ **Встроенный плеер** прямо на сайте в 1 клик.
- 🎲 **Кнопка «Случайный выпуск»**.
- ⭐ **Избранное** с сохранением в браузере.
